# Build Photo Examples

These photos show one completed hand-built module using the current firmware and C/D-swapped jack wiring.

Files:
- `01-front-panel-home.jpg` - front panel, home screen, encoder, and four output jacks.
- `02-main-board-wiring.jpg` - main perfboard wiring with Nano R4, buffer IC, power header, and off-board harnesses.
- `03-side-stack-profile.jpg` - side profile showing board spacing, display stack, and panel mounting.
- `04-jack-wiring-detail.jpg` - rear view of off-board jack wiring.
- `05-output-menu-time.jpg` - output menu showing the `TIME` page.
- `06-pattern-menu-slicer.jpg` - pattern menu showing `SLICER`.
- `07-preset-save-menu.jpg` - preset menu showing `SAVE`.

These are reference photos, not a substitute for the schematic. Use the schematic and manual for electrical connections, then use these photos as physical layout examples.
